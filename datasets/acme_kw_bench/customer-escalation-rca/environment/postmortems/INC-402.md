# Postmortem: INC-402 (OAuth Token Introspection Cache Stampede)

- **Incident ID**: `INC-402`
- **Owning Team**: `Auth-Platform`
- **Root Cause**: Redis TTL expiration across all regional token introspection shards simultaneously triggered DB connection pool exhaustion during peak login traffic.
- **Action Item & Remediation ETA**: Roll out jittered TTLs and request coalescing (`singleflight`) by **`2026-10-15`**.
